*******************************************
Hawaii Island Lava Flow Simulation Project
*******************************************

This document provides a comprehensive technical overview of the 
interactive lava flow simulation application designed for use on Hawaii's Big Island. 
The application serves as a visual aid for community education regarding volcanic hazards.

*******************************************
Features
*******************************************

- Interactive map interface for vent selection
- Parameter configuration for viscosity, vent size, and effusion rate
- Video based flow animations with alpha channel transparency
- Real time simulation control including run, pause, and reset

*******************************************
How to Add New Vents
*******************************************

The project uses a quadrant-based search system to find the nearest vent to a user's click. 
Follow these steps to expand the simulation library:

	1. Add Metadata: Place the new simulation metadata .json file in the mlv_json folder.
	
	2. Add Video Assets: Ensure the corresponding animation videos are placed in the animation_videos directory.
	
	3. Register Location: Open vent_locations.py and identify the correct quadrant based on the vent's longitude. 
	   Add the vent entry to the vents dictionary:
       "vent_id": {"json": "filename.json", "coords": [latitude, longitude]}.
	   
	4. Validation: The vent_utils.py script will automatically use the Haversine formula to include this new vent 
	   in distance calculations during the next runtime.

*******************************************
How to Add New Overlays
*******************************************
This project is built so that you can add/remove overlays as you desire. Overlays that
you want to show up must be KMZ or KML format. 

	To add:
	1. Drop your KMZ file into the overlayers folder.
	2. Add your file to the "overlay_config.py" script. 
	   - In the OVERLAY_LAYERS list:
		First add a comma after the last entry in the list
		Follow this format: ("Name to appear in the list", "file_name.kmz")
	The layers will automatically populate in the overlay drop down list.

	To delete:
	1. Delete the KMZ file from the overlayers folder. (Or don't - as long as you 
	do step 2, no option to turn that overlay on will exist.)
	2. Delete the overlay's entry in the OVERLAY_LAYER's list. This will
	prevent the overlay option from showing up in the list.
	
	
*******************************************
System Architecture Overview
*******************************************

The application follows a modular architecture that bridges a Python backend with a web-based map interface.

The Frontend (Python and PyQt5):

The main interface is managed by lava_gui.py, which handles user inputs like viscosity toggles and simulation
controls. It uses a QWebEngineView to host the interactive map and a QSplitter to manage the layout between the 
controls and the map area.

The Map Bridge (JavaScript and QWebChannel):

To allow communication between the map and Python, the project utilizes a MapBridge class. When a user clicks 
the map, a JavaScript event captures the coordinates and sends them to the Python sendCoordinates slot. 
The Python backend then processes these coordinates to identify the nearest simulation vent.

What's in the Box?
*******************************************
FOLDERS:
animation_videos: All lava flow animations, each stored within a folder that is named after their vent. 
	MLV60 means Mauna Loa Vent 60. 
	Vent numbers were arbitrarily chosen. 
	MLV prefix = Mauna Loa Vent
	KV prefix = Kilauea Vent
images: Any images go here (icon, etc)
js: JS scripts
vent_json: Vent JSON files go here
overlayers: Overlay KMZ files go here
src: Python Scripts

PYTHON:
dark_style_sheet.py: Style sheet for dark mode
lava_gui.py: Everything GUI related - buttons, layout, play functionality, parameters
light_style_sheet.py: Style sheet for light mode
main_window.py: Hit run here to start up the program
map_creator.py: For creating map area
overlay_config.py: Where text descriptions and file links for overlays go
scrubber.py: Anything pertaining to building the scrubber is here
text_descriptions.py: This is where all longer text descriptions are stored. 
theme_manager.py: Logic for managing the themes and their styles
themes.py: Tracks and gets styling for existing themes
vent_locations.py: List of all vents, broken into 4 quadrants.
vent_utils.py: For calculating closest vent and getting data 

JS:
leaflet-kmz.js: This is the KMZ plugin from Raruto.
legend.js: For building lava hazard zone legends. 
map_bridge.js: Functionality for overlays and animation playing
map_helpers.js: Definition of the auto zoom function. 

*******************************************
Data Pipeline and Technical Specifications
*******************************************

The simulations are pre-rendered to ensure smooth performance during live presentations.

Map Resolution: Simulations are generated using a 10 meter resolution map to ensure topographic accuracy.

Coordinate System: Geographical data is processed using the EPSG: 32605 coordinate system to maintain correct 
scaling for the Big Island.

Animation Assets: Simulation results are converted from raw data into transparent .webm or .mov videos. 
These assets are overlaid onto the Folium map using the playVideoOverlay function in the JavaScript layer.

*******************************************
Scientific Parameters and Lava Values
*******************************************

The simulation behavior is governed by specific physical constants to reflect realistic volcanic activity on 
Mauna Loa and Kilauea.

- Global Constants:
	- Denisty: 2700 kg/m^3
	- Gravity: 9.8 ms/s^2
	
Flow Specific Parameters:

Parameter				Pahoehoe Value		‘A’ā Value

Viscosity				250 Pa*s			1200 Pa*s
Cohesion				500 Pa				1000 Pa
Effusion Rate (Low)		20 (dt_mult)		40 (dt_mult)
Effusion Rate (High)	100 (dt_mult)		300 (dt_mult)
